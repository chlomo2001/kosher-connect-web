# Competitive idea-hunt — 2026-07-17 (big-tech / premium products)

An idea-scout pass over live product & help pages of best-in-class software,
mining concrete, adaptable ideas for KosherConnect. Inspiration research — we
draw on publicly visible product design, not code or proprietary assets. The
groomed, prioritised subset is folded into `ops/loops/kc-improve/BACKLOG.md`;
this file keeps the full list + sources.

**Safe** = offline-verifiable, no money/auth/consent surface → eligible for the
autonomous loop. **⚠** = touches money / consent / comms → human-in-the-loop.

## Top picks (novel / high-leverage)
- **Undo toast on every destructive action** + **Shift+? shortcut overlay** — cheap,
  no money/auth surface, universally verifiable → ideal loop fuel.
- **SMS "reply A to approve"** (RepairShopr) for CD→MP3 jobs and rental extensions —
  turns a phone call into one keystroke for the customer.
- **Per-SIM data-usage bar with 25%/10% low-balance nudges** (Airalo/Holafly) — makes
  the SIM/IVR module feel like a real telecom app; drives top-up revenue.
- **Non-refundable damage waiver as a ~5% line item** (Goodshuffle) — a deposit
  alternative that removes the hold/refund return workflow.
- **Idempotency key on every charge/ledger write** (Stripe) — highest-leverage safety
  pattern for KC's append-only money layer.
