## Resume protocol (survives compaction / the 5-hour gate / a session restart)

This audit is a **loop**: run a round → verify → dedupe into this file → launch the
next round → repeat until findings dry up or the context/time gate is hit. If the
5-hour usage gate closes work, resume when it reopens. The state below is the
single source of truth, so a `/compact` or a fresh session can continue cleanly.

**To resume, do this:**
1. Read this file top-to-bottom — the "Confirmed findings" + "Plausible" lists ARE
   the carry-forward memory.
2. Check the running/last workflows:
   - Correctness audit — script `scratchpad/audit.mjs`, latest run **`wf_419a8c3f-9cb`**.
   - Design research — script `scratchpad/design-research.mjs`, latest run **`wf_81d717fe-8e6`**.
   - Same-session: resume with `Workflow({scriptPath, resumeFromRunId})` (cached
     agents return instantly). If those scripts/run-ids are gone (container was
     reclaimed), just re-author an equivalent round from the methodology below.
3. Launch the next correctness round by passing the already-confirmed +
   already-plausible + already-rejected titles as `args.seen` so finders hunt
   only NEW or materially-deeper defects.
4. Append results here, commit, push to `claude/branch-status-check-ez7s3t`.

**Methodology (so a round can be re-created from scratch):** 13 dimensions —
money-math, ledger-idempotency, cron-sweep, stripe(new), portal-auth(new),
documents(new), authz-core, ssr-routing(new), api-validation, data-layer,
migrations/RLS, client-logic(main.js), design-ux. Each dimension = one expert
finder pointed at real files → returns {title, severity, file, line, whatsBroken,
failureScenario, fix}. Each finding → **3 independent adversarial skeptics**
(lens 1 reproduce, lens 2 find-the-guard, lens 3 fix-&-severity); keep on a
**majority of 3** (CONFIRMED), flag on 1/3 (PLAUSIBLE), drop on 0/3. Never kill or
restart a dev server; finders may run `node --test test/*.test.mjs` only.
